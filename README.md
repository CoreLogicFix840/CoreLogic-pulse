# CoreLogic-pulse
Zero-footprint portable Windows 10/11 hardware, thermal, and system health diagnostic utility
========================================================================
  CORELOGIC PULSE v1.0 - ZERO-FOOTPRINT WINDOWS DIAGNOSTIC & HEALTH TOOL
========================================================================

WHAT IS CORELOGIC PULSE?
CoreLogic Pulse is a lightweight, portable Windows utility designed to 
give everyday PC users and technicians instant visibility into system 
health, hardware performance, and stability—without installing bloatware, 
background services, or telemetry trackers.

KEY FEATURES:
* Live System Telemetry: Real-time CPU, RAM, and thermal monitoring.
* Hardware & Battery Audit: Checks CPU, RAM stick configuration, SSD 
  health status, and laptop battery wear capacity.
* Network & Connectivity Check: Instant ping latency and DNS status view.
* Zero Footprint: Runs directly in memory from any folder or USB drive 
  and leaves zero registry clutter behind when closed.

HOW TO RUN (3 SIMPLE STEPS):
1. Extract all files from the ZIP archive into a folder on your PC or USB.
2. Double-click the launcher (.bat) file to open CoreLogic Pulse.
   (Optional: Right-click the launcher and select "Run as administrator" 
   for deeper hardware and network diagnostics.)
3. Close the window when finished—nothing stays running in the background.

SYSTEM REQUIREMENTS:
* Windows 10 or Windows 11 (64-bit)
* No third-party runtimes or installers required.
